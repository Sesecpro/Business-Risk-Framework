# Sesecpro Business Risk Framework

Este repositorio contiene el marco estratégico de gestión de riesgos de ciberseguridad desarrollado por **Sesecpro**. Está diseñado específicamente para la Alta Dirección (CEO, CFO) y Consejos de Administración de organizaciones que buscan transformar la ciberseguridad de un centro de costes a una ventaja competitiva estratégica.

## Filosofía del Framework

En el entorno geopolítico y regulatorio actual (NIS2, DORA), la ciberseguridad ha dejado de ser un desafío técnico para convertirse en un **riesgo de negocio sistémico**. Este framework proporciona las herramientas conceptuales para cuantificar, gestionar y comunicar el riesgo tecnológico en términos de impacto corporativo.

## Estructura del Framework

El framework se divide en cuatro pilares fundamentales:

1.  **[Metodología de Clasificación de Riesgos](risk_methodology.md)**: Taxonomía que vincula fallos técnicos con impactos operativos, legales, reputacionales y financieros.
2.  **[Matriz de Criticidad de Activos](asset_criticality.md)**: Guía para la identificación y priorización de las "Joyas de la Corona".
3.  **[Framework de Resiliencia: El Ciclo Sesecpro](resilience_framework.md)**: Proceso holístico de Identificación, Protección, Detección y Respuesta.
4.  **[Entregables para el Board](board_reporting.md)**: Guía de métricas estratégicas (KPIs y KRIs) para la toma de decisiones.
